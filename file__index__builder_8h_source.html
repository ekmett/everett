78 // The ordinary index builder with a bounded borrowed-FC file sink. Native
79 // storage is pinned, not copied. The caller supplies trusted samples and
80 // exact native/target identities, retaining those dependencies through sealing
81 // and publication. Counts do not authenticate sample contents or identities.
82 // Each step budgets occurrences; key bytes and final navigation construction
83 // remain additional work. Only finish seals a complete IX02 object: there is
84 // no durable partial-output checkpoint or resumed-job API. An external Ops
85 // object supplied by reference must outlive the builder.
